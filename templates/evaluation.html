Academic Project Defense Context: Why Hybrid AI?

In academic machine learning research, standalone text classifiers often achieve high benchmark scores on static test datasets. However, in real-world cybersecurity, attackers continuously evolve novel evasion tactics (such as image-only emails, homoglyph domain deception, zero-font text, and weaponized macros) that bypass pure NLP vectorizers.

For this reason, MailShield does not rely exclusively on machine learning. Instead, it deploys a Hybrid Decision Engine that fuses ML text probabilities with deterministic lexical URL heuristics, sender identity validation, RFC header verification, and attachment metadata analysis.
