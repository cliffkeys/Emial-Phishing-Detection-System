About Project & System Architecture

Design and Implementation of an Email Spam and Phishing Detection System

Academic Project Abstract

Email continues to be the primary attack vector for cyber threats including credential harvesting, business email compromise (BEC), ransomware dissemination, and unsolicited promotional spam. Conventional single-point detection mechanisms (such as pure keyword filtering or uncontextualized blacklists) fail against dynamic domain spoofing, URL obfuscation, and linguistic social engineering.

This project presents MailShield, a defensive cybersecurity platform that combines Natural Language Processing (NLP), Machine Learning (TF-IDF + Naive Bayes), Lexical URL Decomposition, Sender Identity Verification, and Transport Header Analysis (SPF, DKIM, DMARC) into a unified Hybrid Risk Synthesis Engine. The system classifies incoming emails into Safe, Spam, Phishing, or Suspicious while generating explainable indicators and actionable remediation guidance.

Primary Objectives
  • Implement a robust RFC 822 & form-based email parser capable of extracting headers, MIME parts, URLs, and attachments.
  • Train and evaluate a supervised Machine Learning spam classification pipeline with TF-IDF n-grams.
  • Build a static URL decomposition engine evaluating IP hosts, TLDs, shorteners, Punycode, and brand spoofing.
  • Develop sender spoofing checks detecting display-name deception and Reply-To inconsistencies.
  • Synthesize multi-vector signals into an explainable risk scoring framework with automated PDF audit reports.
